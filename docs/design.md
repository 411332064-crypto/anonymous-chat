# 畫面設計：Ranunculus Hall

> 這份文件整理 `/design` 的設計結果，給前端實作（`/frontend-design`）使用。
> 畫面「有什麼、會做什麼」以 `docs/architecture.md` 第 7 節為準，這份文件只規定「長什麼樣子」。
> 設計稿（畫布，只有擁有者看得到）：https://claude.ai/artifact/Cg4QP15q12Mwhe9PNnabf7

---

## 1. 名稱與風格

- **聊天室名稱**：`Ranunculus Hall`（毛茛花的學名）
- **副標**：`après l'hiver`（法文「冬天過後」）
- **進入畫面標語**：冬天過後的舊舞廳，留一盞燈給晚到的人。
- **風格**：冬天過後的舊舞廳，浪漫又帶一點憂鬱；復古歐洲、像褪色的底片照片、安靜優雅。
  - 淺色模式：午後的舊信紙
  - 深色模式：夜晚燭光下的舞廳
- **原則**：
  - 手機優先，不管什麼寬度都不能左右捲動。
  - 裝飾全部是原創，不用任何現有角色或品牌圖案。
  - 不用 emoji，圖示一律用細線條的 inline SVG。

## 2. 顏色

建議在 CSS 裡用變數（`:root` 定義），深色模式用 `@media (prefers-color-scheme: dark)` 覆蓋，跟著系統設定切換。

> 斷線提示條、錯誤、洗版提示的淺色版在畫布上沒有畫，上表的淺色值是依照同一套配色補上的。

## 3. 字體

從 Google Fonts 載入：

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,500;0,600;1,500;1,600&family=Noto+Serif+TC:wght@400;600&display=swap">
```

| 用途 | 字體 | 大小 / 粗細 |
|---|---|---|
| 進入畫面標題 `Ranunculus Hall` | Cormorant Garamond 斜體 | 42px / 600 |
| 頂端列標題（手機） | Cormorant Garamond 斜體 | 24px / 600 |
| 頂端列標題（電腦） | Cormorant Garamond 斜體 | 32px / 600 |
| 副標 `après l'hiver` | Cormorant Garamond 斜體 | 15–16px，字距 0.14em |
| 訊息時間 `14:05` | Cormorant Garamond 斜體 | 15px |
| 字數 `512 / 500` | Cormorant Garamond | 16px / 600 |
| 訊息內文 | Noto Serif TC | 16px，行高 27px |
| 介面文字（按鈕、標籤） | Noto Serif TC | 15–17px，按鈕 600 |
| 次要文字（說明、進出提示、名單） | Noto Serif TC | 13px |

- 字體堆疊：`'Noto Serif TC', serif`，以及 `'Cormorant Garamond', serif`。
- 中文**不要**用斜體（瀏覽器會硬把字壓斜，很難看）。
- 輸入框字體至少 16px，避免 iPhone 點下去時自動放大畫面。

## 4. 質感與裝飾

| 細節 | 做法 |
|---|---|
| 底片顆粒 | 整個畫面最上層蓋一張 inline SVG 雜訊（`feTurbulence` fractalNoise，baseFrequency 0.9，numOctaves 2，去色），設定 `pointer-events: none`。淺色：`mix-blend-mode: multiply`，透明度 0.16。深色：`screen`，透明度 0.07 |
| 褪色暗角 | 根元素 `box-shadow: inset`。淺色 `0 0 140px rgba(110,80,50,.22)`（電腦 220px）；深色 `0 0 180px rgba(0,0,0,.6)` |
| 信紙氣泡 | 圓角 12px，靠說話者那一側的上角改成 2px，像信紙的折角。內距 8px 14px 9px。背景用 `repeating-linear-gradient` 畫每 27px 一條 1px 的淡橫線，`background-position: 0 8px` 讓橫線對齊文字行。淺色加 `box-shadow: 0 1px 2px rgba(58,42,34,.08)` |
| ❧ 花飾 | Unicode 字元 U+2767，用霧金色。放在：進入卡片上方（30px）、名單標題前、進出提示前、空白狀態（48px）、電腦版標題旁 |
| 金色分隔線 | 手繪 SVG：兩段橫線，中間一個 S 形小捲曲加一個小圓點（180×14）。空白狀態用簡化版：兩段線加一個圓點 |
| 雙線邊框 | 頂端列下緣、輸入區上緣、電腦版名單左緣：`3px double`（金色邊框色） |
| 邀請卡外框 | 進入卡片 `border: 1px` 加上 `outline: 1px` 往內縮 8px，形成雙框。淺色加一層柔和的陰影 |
| 蠟燭（深色進入畫面） | 22×34 的細線 SVG：火焰、燭芯、燭身、底座，取代 ❧ 的位置 |

## 5. 版面與尺寸

- **斷點**：寬度 768px 以上用電腦版排版，以下用手機版。
- **觸控目標**：所有按鈕至少 44px 高。
- **間距**：頁面左右 16px（手機）／32px（電腦）。訊息之間 14px（電腦 16px）。
- **按鈕圓角**：3px；名單膠囊和「新訊息」按鈕 999px。
- **訊息最大寬度**：手機 82%，電腦 72%。訊息欄最寬 760px，置中。
- **電腦版名單**：右邊欄，寬 280px。
- **長字串**：氣泡加上 `overflow-wrap: anywhere` 和 `white-space: pre-wrap`（保留換行、自動折行）。

## 6. 各畫面的樣子

畫布上的畫面名稱寫在括號裡。

### 6.1 進入畫面（手機・進入畫面／手機・連線失敗）
- 頂端：展示模式標示條（置中、13px），只在模擬模式出現。
- 畫面正中：邀請卡（雙框），由上到下：❧（深色換成蠟燭）→ `après l'hiver` → `Ranunculus Hall` → 標語 → 金色分隔線 → 「你的代號」標籤、輸入框（48px 高）、說明「1～20 個字，可以和別人重複」→「進入」按鈕（50px 高，滿版寬，字距 0.3em）→「不必登入 · 不留任何紀錄」。
- 連不上時：「進入」按鈕下方出現錯誤區塊，左邊是「無法連線，請稍後再試」，右邊是外框樣式的「重試」按鈕。
- 「連線中…」狀態：畫布上沒有畫。做法是「進入」按鈕的文字換成「連線中…」，並且不能按，顏色不變。

### 6.2 頂端列（所有聊天室畫面）
- 左邊：`Ranunculus Hall`（強調色），下面一行小字「你的代號：小明」。太長時用 `…` 截斷。
- 右邊：外框樣式的「離開」按鈕。
- 電腦版：標題、❧、副標排成一行，「你的代號」和「離開」靠右。

### 6.3 斷線提示條（手機・斷線中）
- 在頂端列正下方，整條黃色，置中。左邊一個重新整理的小圖示，文字是「連線中斷，正在重新連線…」。

### 6.4 在線名單
- **手機**：在頂端列下方。第一行是「❧ 線上 N 人」（13px），下面是膠囊形狀的代號（13px，行高 24px），自動換行，最多兩行（最大高度 58px），超過的話名單區塊內部上下捲動。自己的膠囊用自己的氣泡色。
- **電腦**：右邊欄，標題「❧ 在場的人」（Cormorant 斜體 22px），右邊是「線上 N 人」。下面一人一行，前面一個 6px 小圓點（別人是金色，自己是強調色），自己那一行用自己的氣泡色當底色。欄位最下面是「不必登入 · 不留任何紀錄」。

### 6.5 訊息區
- **別人的訊息**：靠左。上面一行是代號（13px，粗體，強調色）和時間（Cormorant 斜體），下面是信紙氣泡。
- **自己的訊息**：靠右。上面一行時間在左、代號在右，下面是自己顏色的氣泡。
- **未送出**：氣泡改成虛線框、顏色稍微變淡，氣泡下方靠右顯示「ⓘ 未送出」（錯誤色，13px，圖示用 SVG 畫）。
- **進出提示**：置中一行 13px 次要文字，前面加金色 ❧，例如「❧ 薇拉 進入了聊天室」。
- **空白狀態**：區塊正中由上到下是金色分隔線、大的 ❧、「還沒有人說話，打個招呼吧」、金色分隔線。
- **「有 N 則新訊息」**：浮在訊息區底部正中，膠囊形狀，強調色底、按鈕文字色，44px 高。左邊一個向下箭頭的 SVG，有柔和的陰影。

### 6.6 輸入區
- 雙線上緣。左邊是輸入框（最少 44px 高，可以長高，最高約 120px；`placeholder` 是「寫一張短箋…」），右邊是「送出」按鈕（44px 高）。
- 「訊息」的 `<label>` 只給螢幕閱讀器讀，畫面上看不到。
- **電腦版**：輸入框預設兩行高，下面一行小字「Enter 送出 · Shift+Enter 換行」。
- **限制狀態**（手機・字數與洗版限制）：輸入框上方多一行，左邊是洗版提示「◷ 送太快了，稍等一下」，右邊是字數「512 / 500」（錯誤色）。超過字數時，輸入框框線改成錯誤色，「送出」變成不能按的樣式。
